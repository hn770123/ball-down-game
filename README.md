# ボール合体パズルゲーム 仕様書

[プレイはこちら](https://hn770123.github.io/ball-down-game/)

## 1. 概要
上からボールを落とし、同じ色のボール同士をぶつけてより大きなボールに変化させていく、スマートフォン向けブラウザパズルゲームです。
本ゲームは **HTML + CSS + JavaScript** のみで実装され、サーバーサイドの処理を持たず、**GitHub Pages** で公開して遊ぶことを前提とします。

## 2. 動作環境
- **対象デバイス**: スマートフォン (iOS / Android) のブラウザ
- **プラットフォーム**: GitHub Pages（静的ホスティング）
- **開発言語**: HTML, CSS, JavaScript (必要に応じて軽量な物理演算ライブラリを利用)

## 3. ゲームの基本ルール
1. 画面上部からボールを落とし、容器（フィールド）内に積み上げていきます。
2. **同じ色のボール同士が触れ合うと合体**し、一段階大きな別の色のボール1つに変化します。
3. 合体するごとに**スコア**が加算されます。
4. ボールが積み上がり、画面上部に設定された**デッドライン（制限ライン）を越えるとゲームオーバー**になります。

## 4. ボールの種類と進化（全8段階）
ボールは全部で8種類（8段階の色とサイズ）が存在します。数字が大きくなるほどボールのサイズが大きくなります。

1. **ピンク** (最小)
2. **赤**
3. **青**
4. **紫**
5. **黄色**
6. **緑**
7. **茶色**
8. **黒** (最大)

- **最大ボール（黒）の仕様**:
  黒色のボール同士が触れ合った場合、それ以上大きなボールにはならず、**両方とも弾けて消滅**します。この際、通常の合体よりも高いスコアが加算されます。

## 5. 落下するボールについて
- プレイヤーが操作して上から落とすボールは、**小さいボール（1.ピンク、2.赤、3.青）の3種類の中からランダム**に出現します。
- 最初から大きなボール（4.紫以降）が落ちてくることはありません。
- 画面上のどこかに「**次に落ちてくるボール（Nextボール）**」を予告表示します。

## 6. 操作方法とUI（スマートフォン向け）
- **操作方法**:
  - 画面の任意の場所をタップし、指を離す（またはスワイプで位置を調整して離す）と、その位置の真上からボールが落下します。
- **UI構成**:
  - **スコア表示**: 現在の獲得スコアを画面上部などに表示。
  - **Nextボール表示**: 次に落下するボールの種類を予告表示。
  - **デッドライン**: ゲームオーバーの判定基準となる線を薄く表示。

## 7. スコア計算（案）
- 合体してできるボールのサイズが大きいほど、高いスコアを獲得できます。
- 黒ボール同士を消滅させた場合は特大ボーナススコアが入ります。
- （※具体的な配点については実装時にバランスを見て調整します）

## 8. 開発ステップ（今後の展望）
1. **基本ロジックの実装**: 物理演算ライブラリ（例: Matter.jsなど）を用いた落下と衝突判定の実装。
2. **合体処理**: 衝突したボールのサイズと色を判定し、新しいボールを生成する処理の追加。
3. **ゲームサイクル**: スコア計算、Nextボール表示、デッドライン判定（ゲームオーバー）の実装。
4. **調整・公開**: スマホ向けのタッチ操作の最適化、デザインの調整を行い、GitHub Pagesへデプロイ。
